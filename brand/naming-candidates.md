# Naming candidates — AI intake sub-brand of Imbas Solutions

**Date of checks:** 2026-07-29
**Method:** every `.com` verified live via Verisign RDAP
(`curl -s -o /dev/null -w "%{http_code}" https://rdap.verisign.com/com/v1/domain/NAME.com`).
**HTTP 404 = available, HTTP 200 = registered.** All ten finalist domains were
additionally cross-checked with `whois` and returned `No match` — two independent
sources agree. `.ai` checked via `https://rdap.identitydigital.services/rdap/domain/NAME.ai`.

Roughly 290 domains were checked to produce this list. **Every candidate below has a
verified-available domain I would actually register.** Nothing is padded.

## Caveats — read these

### The trademark column is a SCREEN, not a CLEARANCE
Every entry above is the result of web searches only (`"<name>" trademark`,
`"<name>" software OR SaaS OR AI`, plus a look for an adjacent-space company).
**This is not a USPTO TESS search and it is not legal advice.** It catches obvious,
visible collisions and nothing else. Before you print a card, buy a logo, or file
anything, pay a trademark attorney to run a real clearance in the relevant classes
(likely 42 and 35). A screen that comes back clean is not a green light.

### Social handles were NOT checked — deliberately
I attempted automated probes of `instagram.com/<handle>` and `x.com/<handle>`.
Both returned **identical results for a known-nonsense control string**
(Instagram 200 for everything behind its login wall; X 404 for everything behind
its bot block). The probes carry zero signal, so reporting them would have been
fabrication. **Check these by hand in a logged-in browser before you commit.**
Given the coined names in the shortlist, handle availability is likely but unverified.

### Hard filter applied
No candidate contains *law, legal, counsel, attorney, firm, case,* or *esq*.
Checked and confirmed across all 15.
